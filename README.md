# Fundraising and charity

A collection page of live dashboards on how charities raise money, look after their supporters and account for every pound.

**Live page:** https://farzad-vaziri.github.io/fundraising-and-charity/

One static page (`index.html`) served by GitHub Pages from `main`. Images are in `assets/previews/`, and fonts (Fraunces and Work Sans, SIL Open Font License) are self-hosted in `assets/fonts/`. There is no build step.

Every dashboard on the page links to its live Streamlit app. Four of the six use simulated data about a fictional charity.
